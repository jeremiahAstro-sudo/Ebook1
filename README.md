# Garden Reading Room — static website files

These files are the whole website. Upload the contents of this folder (not the folder itself) to the top level of a GitHub repository, then enable GitHub Pages from the `main` branch and `/(root)`. No build step or server is needed.

- Add books and access tokens in `books.js`.
- Add optional public Giscus settings in `settings.js`.
- Put optional public PDFs in a `books/` subfolder and set `pdfPath` on the book.

Read the project guide at `../README.md` for full examples and important token/privacy limits.
